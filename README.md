# schedule-parser

Небольшой неофициальный проект для выгрузки расписания МГТУ «СТАНКИН» в JSON.

Смысл простой: не возиться руками с PDF и иметь готовые JSON-файлы, к которым можно обратиться из приложения или любого другого сервиса.

По сути скрипт:

- Логинится в ЭОС через `SCHEDULE_LOGIN` и `SCHEDULE_PASSWORD`;
- Находит папки с расписанием на странице курса;
- Скачивает PDF с расписаниями групп;
- Парсит их в JSON;
- При необходимости публикует готовые JSON-файлы в ветку `schedules` через GitHub Actions.

Локальный запуск:

```bash
python main.py
```

Для GitHub Actions нужны secrets репозитория:

- `SCHEDULE_LOGIN`
- `SCHEDULE_PASSWORD`

## Важно

- Проект не аффилирован с МГТУ «СТАНКИН»;
- Репозиторий сделан в некоммерческих целях просто для более удобного доступа к расписанию;
- Если публикация этих данных противоречит правилам университета или по запросу представителей МГТУ «СТАНКИН» окажется нежелательной, репозиторий будет закрыт или приведён в соответствие требованиям.
