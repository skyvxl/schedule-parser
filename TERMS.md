## 2. Описание приложения

**Pairs** — неофициальное некоммерческое iOS-приложение, позволяющее просматривать расписание занятий МГТУ «СТАНКИН» в удобном формате.

Принцип работы:

- пользователь выбирает свою учебную группу;
- приложение загружает данные расписания из публичного репозитория разработчика;
- данные кэшируются локально на устройстве;
- дальнейший просмотр расписания доступен без подключения к интернету.

Данные расписания получены разработчиком путём автоматизированной обработки
PDF-файлов с учебной платформы МГТУ «СТАНКИН» и преобразованы в JSON-формат.

Пользователь не взаимодействует с учебной платформой университета напрямую
и не передаёт никаких учётных данных через приложение.

Приложение **не является официальным** продуктом или сервисом МГТУ «СТАНКИН» и **не аффилировано** с университетом.

## 3. Точность данных

Данные расписания формируются путём автоматизированного парсинга PDF-файлов
с учебной платформы МГТУ «СТАНКИН». В процессе обработки PDF возможны
технические неточности, ошибки распознавания или потеря части данных.

Данные обновляются вручную разработчиком по мере необходимости и могут
не отражать актуальное расписание на момент использования приложения.

Разработчик не гарантирует:

- точность и полноту данных расписания;
- актуальность данных при изменении расписания университетом;
- отсутствие ошибок, возникших в процессе парсинга PDF;
- совпадение данных с официальным расписанием МГТУ «СТАНКИН».

**Пользователь обязан самостоятельно проверять расписание по официальным
источникам МГТУ «СТАНКИН» в случае возникновения сомнений.**
